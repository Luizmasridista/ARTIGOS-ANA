# ADR-002: Stack — Electron + React + Go

Status: aceito | Data: 2026-08-27 | Autor: techlead (via orquestrador)

## Contexto

App desktop local (Windows), produto "Artigos Ana", público estudante. Decidido com o usuário: Electron no app e backend em Go simples.

## Decisão

- **App:** Electron + React + TypeScript (Vite), tema claro/escuro.
- **Backend:** Go 1.26, stdlib `net/http` com o roteador nativo (Go 1.22+), sem framework web.
- **Banco:** PostgreSQL 18 local (porta 5432, banco `artigos_ana`), acessado via `github.com/jackc/pgx/v5` com o adaptador stdlib (database/sql). Troca em relação ao SQLite inicial: os dados precisam persistir quando o app está fechado (banco fora do processo, nada é apagado no cold down) e o usuário já tem o PostgreSQL instalado na máquina, então a migração não adiciona dependência nova. Conexão configurável por variáveis de ambiente (`PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`, `PGDATABASE`) ou flag `--db-url`; o schema é criado no startup com `CREATE TABLE IF NOT EXISTS` e há uma tabela `historico` para controle de versão das alterações.
- **PDF:** poppler-utils (`pdftotext -bbox`, `pdftoppm -png`) com binários Windows baixados do release `oschwartz10612/poppler-windows` e guardados em `backend/bin/`. Motivo: renderização e extração confiáveis e fiéis; binários são empacotados junto do app no instalador.
- **DOCX:** geração OOXML direta (archive/zip + XML) — controle total de imagens, camada de texto invisível (`w:vanish`) e notas. Sem dependência de biblioteca DOCX.
- **Comunicação:** Electron main sobe o binário Go em `127.0.0.1:8734`; o renderer consome a API.

## Alternativas rejeitadas

- FastAPI/Python: usuário pediu Go.
- SQLite (`modernc.org/sqlite`): decisão inicial, descartado porque o PostgreSQL já instalado no ambiente do usuário garante durabilidade fora do processo do app, sem custo extra de setup.
- unipdf/unioffice: licenciamento comercial restritivo.
- LibreOffice headless: dependência pesada e resultado inconsistente.
- Geração DOCX via biblioteca go-docx: não controla `w:vanish` e posicionamento fino de imagens.

## Consequências

- Requer baixar os binários do poppler uma vez (script `backend/bin/setup-poppler.ps1`).
- Distribuição final empacota poppler junto (na v1 roda em dev; empacotamento no instalador fica para depois).
